# Iris-Flower-Classification-End-to-End
End-to-end machine learning project for Iris flower classification using Python, Pandas, Matplotlib, and Scikit-learn.

## 📊 Dataset
- **Name:** Iris Dataset
- **Source:** scikit-learn built-in dataset
- **Samples:** 150
- **Features:**  
  - Sepal length  
  - Sepal width  
  - Petal length  
  - Petal width  
- **Target Classes:**  
  - Setosa  
  - Versicolor  
  - Virginica  

---
## ⚙️ Steps Performed

1. Loaded Iris dataset and converted it into a Pandas DataFrame  
2. Performed data exploration (shape, info, describe, missing values)  
3. Visualized feature relationships using scatter plots  
4. Separated features (X) and target (y)  
5. Split data into training and testing sets
